# Renicode 2.2 升级与回退边界

<!-- wiki: {"kind":"discussion","workflow":"confirmed","revision":1,"change":"none","relations":["docs/plans/renicode-upstream-align.md","docs/validation/renicode-align-upgrade.md"]} -->

## 已核实事实

- 本讨论承接已批准的 2.2 对齐计划，不另建重复实施计划。具体实时升级/回退机制仍需确认；2026-10-29 的“继续直到做完”未被解释为接受数据回退损失或允许关闭运行中的服务。
- 当前 A/B 只支持同后台字节、同桌面存储指纹，共用 `ai.renicode.desktop`。新版 CLI 与桌面存储指纹均不同，不能绕过原检查。
- 真正旧 CLI `2.1.4-renicode.1` 与新版 `2.2.0-renicode.1` 在合成独立 profile 的会话/归档/未消费输入、更新、重启与备份恢复检查通过。两版后台 migration journal 均为 54 项且一致，不证明任意真实数据库兼容。
- 桌面新 migration 删除 `extension_file`，将 `extension` 改名为 `plugin` 并留下只读 view。旧版启用设置 UPDATE 已在隔离数据库实际失败。直接切回旧 EXE 不是安全回退。
- 当前未复制、迁移或修改实时 profile，未暂存/激活 A/B，未关闭或重启用户桌面/后台。

## 推荐方案：版本化 profile 代际，原数据不覆盖

1. 保留原安装、原槽位与现有 `ai.renicode.desktop`。新后台/新存储候选使用明确绑定的独立 profile 代际；品牌和 OpenCode 隔离边界不变。不是为普通同指纹桌面更新重复复制所有数据。
2. 可以先构建、验证和暂存新程序，但不让旧 guardian 自动激活不兼容候选。迁移激活须单独记录授权与绑定，不把 `--check`当只读命令。
3. **仅在用户正常退出桌面、旧后台已正常停止后**做一致性复制。后台仍运行或有执行 claim 时拒绝迁移。AI 不强制结束进程，不把等待条件变成无人值守迁移授权。
4. 新代际从该停止点的完整 profile 复制，含桌面 drafts/state/blob、后台数据库/事件/凭据、配置与必要插件资源；缓存可另按清单处理。备份/复制不上传、不入 Git，不打印真实凭据或聊天内容。路径与文件完整性有清单，SQLite 验证完整性与外键，采用临时目标完成后发布。
5. 新版本只操作新代际，拥有独立 service registration/config/CLI staging 和监听端点，不能发现或替换原后台。成功须验证真实桌面、IPC、认证健康、页面和启动器健康上报后才标记活动。
6. 启动失败回退到旧程序与旧代际，不能把旧程序连接到升级后的数据库。新代际保留，不自动删除或覆盖；后续故障回退前也要求正常退出新桌面/后台。
7. **回退的数据语义**：旧代际是升级停止点快照，回退后旧 UI 不自动包含升级后新增聊天/设置。新增数据仍完整保留在新代际，恢复新版可继续使用；跨代际自动合并/导入不在本次范围，不承诺无损同步。

## 代价、替代与未决项

- 推荐方案需要 launcher/profile 绑定与迁移-aware 暂存/激活设计，属于现有未批准的具体升级机制；确认后才写生产实现并增补原计划 revision。
- 需要用户安排一次正常退出和后台正常停止窗口；源码与隔离验证可继续，不要求现在打断当前会话。
- 会占用一个额外 profile 和不可变程序包的磁盘空间。实际数据大小、清单与敏感数据备份位置在授权后核对；不预先读取真实聊天正文。
- 替代方案是原 profile 就地迁移并在失败时恢复整套快照。这会涉及原路径覆盖及升级后数据隔离，风险更高，不推荐；同样须单独确认。
- 若不接受回退只显示升级前状态，则需要另行设计跨版本数据兼容/合并，不能声称本计划已经完成或允许部署。

## 待确认摘要

请确认是否允许实施“版本化 profile 代际 + 保留原数据 + 不自动合并回退后新增数据”的升级机制。确认不授权现在关闭桌面/后台，不授权删除旧数据，不授权无人值守迁移或提交/推送。实际激活窗口由用户正常退出并确认后台已停后安排。

## 实施确认（2026-10-29）

用户在明确回退数据语义、原数据不覆盖与正常退出门禁后选择“版本化 profile（推荐）”，批准实现独立代际、迁移-aware A/B 与隔离验证。接受回退旧 UI 仅显示升级前状态，新版新增数据另外保留；实际迁移等待正常退出窗口。仍不授权现在关闭桌面/后台、删除原数据、无人值守迁移或提交/推送。
